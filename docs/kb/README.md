# Knowledge base

The service desk's articles, written for council staff. `sdlab sn apply` publishes every file here
(except this one) to the **Kestrel IT Help** knowledge base in ServiceNow. Each file starts with a
header:

```
---
title: The article's title, as staff would search for it
category: one of the categories in servicenow/config/knowledge.yaml
keywords: words people type when they look for it
---
```

Write for someone stressed and in a hurry: the fix first, numbered steps, and when to call us.
