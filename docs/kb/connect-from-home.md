Council laptops connect to the council network automatically from any internet connection (Always
On VPN). You don't need to start anything: sign in as normal.

## It is not connecting

1. Check the internet works: open <https://www.gov.uk>.
2. If you are in a hotel or café, open a web page first to accept its terms; the VPN connects
   after that.
3. Restart the laptop.
4. Click the network icon by the clock. **Kestrel VPN** should say **Connected**. If it says
   **Disconnected**, choose it and **Connect**.

Microsoft 365 (email, Teams, OneDrive) works without the VPN. Shared drives and some business
applications need it.

Still stuck? Call the service desk and tell us what the network icon shows.
